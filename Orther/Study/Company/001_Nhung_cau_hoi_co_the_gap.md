# 5. Những câu hỏi có thể gặp khi phỏng vấn

Mình đề xuất chuẩn bị hai nhóm: câu hỏi về công ty và câu hỏi chuyên môn.

## 5.1. Câu hỏi về công ty

Câu 1: Bạn biết gì về Rivercrane Việt Nam?

Bạn có thể trả lời:

"Em tìm hiểu thì biết Rivercrane Việt Nam được thành lập năm 2012, là thành viên của tập đoàn Rivercrane Nhật Bản.
Quy mô công ty: 100+ nhân viên. 

Công ty hoạt động trong lĩnh vực phát triển phần mềm và các hệ thống thương mại điện tử. Một trong những sản phẩm nổi bật của tập đoàn là Webike, nền tảng thương mại điện tử dành cho cộng đồng người yêu xe máy.

Công ty có 100% vốn đầu tư nước ngoài. Văn hóa công ty là : Tôn trọng hòa khí"

---------
Triết lý này đề cao:
- Tôn trọng sự khác biệt giữa các cá nhân.
- Lắng nghe và thấu hiểu đồng nghiệp.
- Hợp tác và điều chỉnh để làm việc hài hòa.
- Tạo môi trường để mỗi nhân viên phát huy năng lực cá nhân.
---------

Câu 2: Tại sao bạn muốn làm việc tại Rivercrane?

Gợi ý trả lời:

"Em muốn tìm kiếm một môi trường có thể giúp em phát triển chuyên môn Backend và tham gia xây dựng các hệ thống có quy mô thực tế.

Qua tìm hiểu, em thấy Rivercrane có các sản phẩm thương mại điện tử và hoạt động phát triển phần mềm cho thị trường Nhật Bản. Đây là môi trường phù hợp với định hướng phát triển lâu dài của em.

Ngoài ra, em cũng mong muốn được học hỏi cách làm việc chuyên nghiệp, quy trình phát triển phần mềm và cải thiện khả năng giải quyết các bài toán kỹ thuật."

Câu 3: Bạn hiểu gì về sản phẩm Webike?

Gợi ý trả lời:

"Webike là hệ sinh thái thương mại điện tử dành cho người sử dụng xe máy, đặc biệt là cộng đồng yêu xe mô tô.

Nền tảng cung cấp các chức năng như tìm kiếm, mua bán phụ tùng, phụ kiện và kết nối cộng đồng người dùng.

Nếu nhìn từ góc độ kỹ thuật, em nghĩ hệ thống này có nhiều bài toán thú vị liên quan đến quản lý sản phẩm, tìm kiếm, đơn hàng, tồn kho và tối ưu hiệu năng."

## 5.2. Câu hỏi chuyên môn Backend Java

Với kinh nghiệm Java/Spring Boot của bạn, mình khuyên ôn các câu sau:

| Chủ đề         | Câu hỏi cần chuẩn bị                            |
| -------------- | ----------------------------------------------- |
| Java Core      | HashMap hoạt động như thế nào?                  |
| Java Core      | HashMap và ConcurrentHashMap khác nhau thế nào? |
| OOP            | 4 tính chất của OOP là gì?                      |
| Collections    | ArrayList và LinkedList khác nhau thế nào?      |
| Multithreading | Thread và Runnable khác nhau thế nào?           |
| Spring         | IoC và Dependency Injection là gì?              |
| Spring         | Bean trong Spring được quản lý như thế nào?     |
| Transaction    | @Transactional hoạt động thế nào?               |
| JPA            | Lazy Loading và Eager Loading là gì?            |
| Database       | Index hoạt động như thế nào?                    |
| Database       | Làm thế nào để tối ưu một câu SQL chậm?         |
| REST API       | PUT và PATCH khác nhau thế nào?                 |
| Security       | JWT Authentication hoạt động như thế nào?       |
| System Design  | Làm thế nào xử lý nhiều request đồng thời?      |

Đừng bỏ qua các câu hỏi tình huống:

- Khi API phản hồi chậm, bạn debug như thế nào?
- Khi một câu SQL chạy mất vài giây, bạn tối ưu ra sao?
- Khi nhiều người cùng mua một sản phẩm nhưng số lượng tồn kho có hạn, bạn xử lý thế nào?
- Khi hai transaction cùng cập nhật một bản ghi, làm sao tránh mất dữ liệu?
- Khi một service phụ thuộc vào service khác bị lỗi, bạn xử lý ra sao?

Đây là những câu hỏi giúp nhà tuyển dụng đánh giá khả năng giải quyết vấn đề chứ không chỉ kiến thức lý thuyết.
